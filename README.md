# VORKAN CLIMB 2.0

Proyecto Android independiente de la versión 1.0.

## Flujo
Mis rocódromos → entrar → foto → marcar presas → guardar bloque.

Cualquier usuario podrá crear un rocódromo. Para ver y publicar bloques en uno ajeno, deberá solicitar acceso y recibir aprobación de un administrador.

Cada bloque tiene su propia foto. No se clasifican las paredes. Los bloques publicados son de solo lectura.

## Plan
1. Reutilizar editor y detector de la versión 1.0, con identificador Android independiente.
2. Construir navegación por rocódromos.
3. Añadir cuentas, membresías, solicitudes y sincronización segura entre móviles.
